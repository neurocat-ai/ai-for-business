# KB01. Общие правила возврата

Версия: 1.4
Область действия: стандартные товары без признаков повреждения или ошибки комплектации.

## Основное правило

Клиент может подать заявку на возврат стандартного товара в течение 14 календарных дней после даты доставки, если товар не использовался, сохранен товарный вид и товар не относится к исключениям.

Создание заявки означает только регистрацию случая для дальнейшей проверки. Оно не означает автоматическое одобрение возврата или перечисление денег.

## Что требуется для первичной заявки

Нужно определить:
- номер заказа;
- товар;
- причину возврата;
- использовался ли товар, если это следует из обращения.

Если обязательных данных нет, сначала запросить их у клиента.

## Что можно сообщить клиенту

Можно:
- объяснить общий срок;
- перечислить необходимые сведения;
- сообщить номер созданной заявки.

Нельзя:
- гарантировать одобрение;
- обещать дату перечисления денег;
- назначать компенсацию.

## Когда не применять общий сценарий

Не использовать этот документ как единственное основание, если:
- товар поврежден при доставке;
- клиент получил не тот товар или заказ неполный;
- товар изготовлен по индивидуальным параметрам;
- срок 14 дней истек;
- есть признаки угрозы безопасности;
- клиент требует индивидуальную денежную компенсацию;
- по заказу уже есть нерешенная заявка.

В этих случаях использовать профильную инструкцию или передать случай человеку.

## Чего в документе нет

Документ не описывает:
- как возвращаются бонусы, подарочные сертификаты или иные способы оплаты;
- сроки фактического перечисления средств после одобрения;
- правила международной доставки.
