# S1 case reference

Внутренний документ для авторов и ревьюеров. Это не единственный правильный ответ.

## Ожидаемая область аудита
Клиентская поддержка после оформления заказа.

## Основные процессы
1. Прием и разбор обращения.
2. Ответ на типовые вопросы.
3. Работа с возвратами и проблемными заказами.
4. Регистрация заявки.
5. Передача сложных случаев.
6. Контроль качества.

## Проблемные участки
- чтение и структурирование длинных обращений;
- поиск правил;
- ошибки выбора инструкции;
- ручной перенос данных;
- пропуски полей;
- поздняя эскалация;
- ограниченный контроль качества.

## Допустимые кандидаты
A. Классификация и резюме обращения - Prompt-tool.
B. Контроль качества ответа - Prompt-tool.
C. Подготовка ответа по внутренним правилам - RAG.
D. Обработка проблемного возврата и регистрация заявки - RAG + Agent.
E. Автоматическая денежная компенсация - высокий эффект, но плохой кандидат из-за рисков, полномочий и отсутствия безопасного финансового контура.

## Что считать хорошим выбором
Хорошим считается не только D. Студент может обоснованно выбрать A, B или C, если связывает задачу с бизнес-целью, сравнивает альтернативы, учитывает ценность, реализуемость, риски и данные, формулирует гипотезу и критерий успеха.

Для сквозного демонстрационного пути эксперт выбирает D, потому что он естественно показывает границу Prompt-tool, пользу RAG и необходимость внешнего действия.

## Данные и готовность
- обращения доступны;
- правила доступны, но распределены по документам;
- данные заказов доступны;
- регистрация заявки технически реализуема;
- автоматическая денежная компенсация не готова по рискам, полномочиям и данным.

## Основные риски
- неверное применение правила;
- устаревшая инструкция;
- потеря фактов;
- ошибочный tool call;
- дублирование заявки;
- обещание результата до подтверждения;
- недостаточная эскалация.

## Концептуальная архитектура золотого кандидата
обращение -> LLM-анализ -> внешний источник знаний -> решение о действии -> подтверждение человека -> business tool -> внешнее состояние -> итоговый ответ.
