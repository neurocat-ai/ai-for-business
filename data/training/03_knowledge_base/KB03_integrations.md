# KB03. Интеграции

Версия: 1.9

## Готовые интеграции

Поддерживаются:
- Slack;
- Microsoft Teams;
- Google Workspace;
- Jira Cloud;
- REST API;
- исходящие webhooks.

## REST API

API позволяет:
- создавать заявки;
- читать статусы;
- обновлять отдельные поля;
- получать список шаблонов.

## Ограничения

Готовой интеграции с SAP нет.
Готовой интеграции с 1С нет.
Такие сценарии могут быть реализованы через API и промежуточный слой, но требуют отдельной оценки.

Нельзя обещать срок или стоимость нестандартной интеграции без технической оценки.
